# Beutl.Extensions.Karaoke

<img src="assets/icon.png" width="96" height="96" alt="">

歌詞を表示し、歌った部分から左へ順に色を変えるカラオケ字幕のBeutl拡張機能です。歌詞はツールタブで取り込み・編集・タイミング付けをして、要素の中に保存します。

## 使い方

1. ライブラリの「カラオケ字幕」をタイムラインに追加します。
2. プロパティパネルの「歌詞」の「編集」を押します。ツールタブ「カラオケ字幕」が開き、そのオブジェクトの歌詞を編集できます。
3. ツールバーの「歌詞を取り込む」（↓のアイコン）を押すと、タブ全体が取り込み画面に切り替わります。
   - **貼り付け**: 歌詞を貼り付けて「取り込む」を押します。時刻付きの LRC でもかまいません。
   - **ファイル**: LRC（文字ごとの時刻にも対応）やテキストファイルを読み込みます。
   - **既存の歌詞**: 今の歌詞と置き換えるか、今の歌詞に追加するかを選びます。
   - 時刻のない歌詞は、4秒間隔で並べて取り込みます。行ごとに開始時刻を設定してください。
   - 「履歴」には、取り込みが新しい順に並び、結果を表示します。
   - 左上の「戻る」（←のアイコン）か Esc キーで編集に戻ります。
4. 歌詞の時刻は要素の先頭から数えます。曲とずれる場合はプロパティの「時刻のずれ」で調整します。
5. 位置は、ほかのオブジェクトと同じように配置やトランスフォームで調整します。
6. 要素の右クリックメニューの「オリジナルの長さに変更」で、最後の行が消えるまでの長さにできます。

歌詞はプロジェクトファイルの中に LRC の形で保存されるので、元のファイルを移動・削除しても表示は変わりません。

要素を分割すると、後半の「時刻のずれ」が分割した位置の分だけ自動で戻るので、歌詞は分割前と同じ時刻に表示され、色も途中から変わり続けます。動画を分割したときと同じく、前半と後半はどちらもすべての行を持ちます。

## 歌詞の編集

ツールタブの左に行の一覧、右に選択した行の編集欄が並びます。タブの幅が狭いときは、編集欄が一覧の下に移ります。ツールバーのボタンはアイコンで、名前はツールチップに表示します。

- タブは、「編集」を押したオブジェクトだけを編集します。タイムラインの選択には追従しません。別のオブジェクトの「編集」を押すと、開いているタブがそのオブジェクトに切り替わります。
- ツールバーの「タイムラインで選択」を押すと、編集している要素をタイムラインで選択します。どの要素かはそのツールチップにも表示します。
- 編集中の要素を削除すると編集欄は隠れ、元に戻すと再び表示されます。
- タブの追加メニューには表示しません。

| 操作 | 方法 |
| --- | --- |
| 選択 | 一覧の行をクリックします。Ctrl（macOS は ⌘）や Shift を押しながらで複数選べます。 |
| 確定 | Enter キーを押すか、別の欄や別の行へ移ります。読み取れない入力は元に戻ります。 |
| 開始・終了 | `1:02.5` のように入力するか、時刻の横の「再生位置にする」で今の再生位置にします。開始を動かすと、文字ごとの時刻も一緒に動きます。 |
| 開始へ移動 | 開始の横の「この時刻へ移動」を押すか、一覧の行をダブルクリックします。 |
| 歌詞 | 書き換えた後も区切りの数が同じなら、文字ごとの時刻を引き継ぎます。数が変わったときは時刻を消すので、付け直してください。 |
| 追加・削除 | ツールバーの「追加」で再生位置から始まる行を追加します。選んだ行は Delete キーかツールバーの「削除」で消せます。 |
| 書き出し・全削除 | ツールバーの「その他」（⋮のアイコン）から、LRC ファイル（UTF-8）への書き出しと、すべての行の削除ができます。 |

すべての編集は、Beutlの「元に戻す」「やり直し」で戻せます。

### 文字ごとの時刻

文字ごとの時刻を付けると、歌に合わせて文字ごとに色が変わります。付けていない行は、行の開始から終了まで一定の速さで色が変わります。

| 方法 | 内容 |
| --- | --- |
| タップで付ける | 「タップで付ける」を押し、タイムラインを再生しながら、文字を歌い始めるたびに「打つ」（T キー）を押します。最後の文字のあと、歌い終わるところでもう一度押すと、まとめて反映されます。詳しくは下の「タップの時刻」を参照してください。 |
| 均等に割り振る | 行の開始から終了まで、文字を同じ間隔で並べます。 |
| 直接入力 | 文字ごとの時刻と「歌い終わり」を入力します。前後の文字の時刻を越える値は、その範囲に収めます。文字を押すと、その時刻へ移動します。 |
| 消す | 文字ごとの時刻を消します。 |

区切りは、かなや漢字は1文字ずつ、小さいかな（「きゃ」の「ゃ」など）は前の文字と一緒、英単語は単語ごとです。句読点や閉じかっこは前の文字に、開きかっこは次の文字に付きます。

#### タップの時刻

再生中のタップは、再生を始めてからの実際の経過時間で記録します。プレビューの再生位置は描画が終わったフレームでしか進まないため、描画が重いと音声より遅れたり止まったりしますが、その影響を受けません。停止中のタップは、そのときの再生位置で記録します。

「最初のタップで再生」がオンのとき（既定）は、停止中のタップで再生が始まります。このタップは記録しません。最後のタップで行が確定すると、再生も止まります。途中で再生を止めた場合は、次のタップで再開します。自分で始めた再生は止めません。オフにすると、自分で再生を始めてからタップします。この設定はタブごとに保存されます。

### 表示方法

| 表示方法 | 内容 |
| --- | --- |
| 2行（交互） | 上段は左寄せ、下段は右寄せで、行を交互に表示します。テレビのカラオケと同じ配置です。 |
| 1行 | 今の行だけを中央に表示します。 |

- 「先に表示する時間」で、歌い始めの何秒前から行を出すかを決めます。前の行がまだ表示中のときは、その行が消えてから出ます。
- 「残す時間」で、歌い終わってから行を消すまでの時間を決めます。
- 歌う前と歌った後の、文字の色と縁取りをそれぞれ設定できます。

## 取り込める歌詞

- `[mm:ss.xx]歌詞` の行。1行に複数の時刻を書いた行（`[00:12.00][01:30.00]サビ`）は、それぞれの時刻に展開します。
- 単語ごとの時刻を書く拡張LRC（`[00:12.00]<00:12.00>き<00:12.40>ら…<00:14.00>`）。単語の中では一定の速さで色が変わります。
- 単語ごとの時刻がない行は、その行の開始から次の行の開始まで一定の速さで色が変わります。
- `[offset:+500]`（ミリ秒、正の値で歌詞が早く出ます）、`[ti:]`、`[ar:]`。
- 文字のない時刻だけの行は、前の行の終わりとして扱います。
- 文字コードはUTF-8です。UTF-8として読めない場合はShift_JISとして読みます。
- 時刻付きの行が1つもないファイルは、時刻のない歌詞として1行ずつ取り込みます。`[ti:]` のようなタグの行は飛ばします。

## 既知の制約

- LRC で表せない形は保存できません。行の終わりは次の行の開始までに切り詰め、時刻はミリ秒単位に丸めます。
- 以前の版で「歌詞ファイル (LRC)」を選んでいた要素は、読み込むと歌詞が空になります。ツールタブから取り込み直してください。
- ふりがな（ルビ）には対応していません。
- フォントは和文のグリフを持つものを選んでください。既定はNoto Sans JPです。和文グリフのないフォントでは色の境目がずれます。

## 開発

`Beutl.Extensibility.Sdk` 2.0.0-preview.9 でビルドします。

```bash
dotnet build src/Beutl.Extensions.Karaoke
```

```bash
dotnet test tests/Beutl.Extensions.Karaoke.Tests
```

テストには、LRCパーサー・保存形式・区切り・表示タイミングの単体テスト、Beutlの `SceneRenderer` でシーンをヘッドレスに描画して色の境目を確認するテスト、Avaloniaのヘッドレス環境でツールタブを操作するテストがあります。描画した画像は `bin/Debug/net10.0/rendered/` に保存されます。

Beutlにサイドロードして試す場合は、次のコマンドで `~/.beutl/sideloads` に出力します。

```bash
dotnet build src/Beutl.Extensions.Karaoke -p:DebugApplication=true
```
